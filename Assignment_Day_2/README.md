# Employee Salary Processing System

## 📌 Design Decisions
- Used **abstract base classes** for extensibility
- Enforced **encapsulation** via protected attributes and validation
- Applied **polymorphism** so main logic treats all employees uniformly
- Separated responsibilities into modules (clean architecture)
- Used functional programming for salary processing
